# 🛒 E-Commerce Platform

A full-stack e-commerce web application that enables users to browse products, manage shopping carts, securely authenticate, and place orders through a responsive and user-friendly interface.

This project was developed to gain hands-on experience in building scalable full-stack applications using modern web technologies while implementing real-world e-commerce workflows.

---

## 🚀 Features

### User Features

- User Registration & Login
- Secure Authentication
- Browse Products
- Search Products
- Product Details
- Wishlist
- Add to Cart
- Remove from Cart
- Update Cart Quantity
- Checkout Flow
- Order Summary
- Responsive User Interface

### Product Management

- View Product Catalog
- Product Categories
- Product Search
- Product Filtering

### Shopping Cart

- Add / Remove Products
- Quantity Management
- Dynamic Price Calculation

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/enm-2001/e-commerce.git
```

### Install Backend

```bash
cd backend
npm install
npm start
```

### Install Frontend

```bash
cd frontend
npm install
npm start
```
